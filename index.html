🔒 Tu privacidad importa
Puedes escribir tu ubicación manualmente o permitir que el celular sugiera dónde estás. La ubicación se utiliza para identificar tu país, región y zona horaria. No se guarda tu posición GPS. Si utilizas la detección automática, las coordenadas se envían a OpenStreetMap Nominatim para obtener el nombre aproximado del lugar. No se utiliza para rastrearte.
Comprueba que corresponda a tu ciudad. Es la que controla el contador.
